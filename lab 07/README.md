# Cafe Hub

## Lab 7 - Express and EJS

### Aim
To develop a dynamic web application using Express.js and EJS templating.

### Features
- Dynamic cafe listing
- Cafe details
- Add cafe
- Profile
- Express routing
- EJS templating
- Form handling

### Technologies
- Node.js
- Express.js
- EJS
- HTML
- CSS
- JavaScript

### How to Run

```bash
npm install
npm start
```

Then open:

http://localhost:3000
